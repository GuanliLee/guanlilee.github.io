# 李观丽的个人主页

这是可直接托管到 GitHub Pages 的静态网页，不需要安装 Node.js，也不需要购买服务器。

## 本地查看

双击 `index.html` 即可查看。请让 `index.html`、`style.css`、`portrait.jpeg`、`robotac-calibration.jpg` 和 `robotac-real-robot.jpg` 保持在同一个文件夹。

## 上线到 GitHub

1. 登录自己的 GitHub，创建一个公开仓库，名称填写 `guanlilee.github.io`。如果这个仓库已存在，先查看现有内容，避免覆盖原网页。
2. 将本文件夹中的 `index.html`、`style.css`、`portrait.jpeg`、`robotac-calibration.jpg`、`robotac-real-robot.jpg`、`.nojekyll` 上传到仓库根目录。不要把整个外层文件夹作为子目录上传。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment → Source** 选择 **Deploy from a branch**。
5. 选择 **main** 分支和 **/(root)** 文件夹，点击 **Save**。
6. 等待发布完成后，访问 `https://guanlilee.github.io/`。这个地址是部署成功后的预期地址，本交付并未替你创建或发布 GitHub 仓库。

官方说明：https://docs.github.com/en/pages/quickstart

## 修改内容

- `index.html`：个人简介、论文、奖项、教育与实习等文字，搜索要改的文字即可定位。
- `style.css`：颜色、字号、间距、手机布局。
- `portrait.jpeg`：替换为新的照片，保持文件名即可。
- 更新后提交到 GitHub，Pages 会重新部署。
